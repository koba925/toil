# 書籍の構成案

書籍は以下のように構成する。

* 導入
  * 全体構成の説明
    * どこで読み終わってもまとまった学びがある
    * ファーストクラスマクロの章はスキップも可
    * 中間コードインタプリタは最初に小さく実装した後はしばらく放置する
* 最小のインタプリタ
  * 最小の評価器
    * 方針
      * 字句解析からは始めない。動かせるものから始める。
      * シンプルなツリーウォーク式評価器として実装する。
      * 扱う値はNone、bool、intのみ。Pythonの値をそのまま用いる。
      * この段階では文字列でシンボルを表す。
        * 字句解析・構文解析を導入する段階でシンボルを表す型を導入して文字列が文字列を表すようにする。
      * ASTはタプルで表す。
      * 環境はdictを用い、ミュータブルな構造として実装する。
    * 値を実装する。
    * 即席の関数を実装する。（あとで正しく作り直す）
    * 複数の式を順番に評価するseqを実装する。
    * if-then-elseを実装する。elifは後で。
    * 変数（定義・参照）を評価する。
    * スコープを実装し、代入を実装する。
    * 組み込み関数を実装する。
    * ユーザ定義関数（動的スコープ）を実装する。
    * ユーザ定義関数（静的スコープ）を実装する。
    * whileを実装する。
  * 余談：クロージャでデータ構造
  * 最小の字句解析・構文解析
    * 方針
      * 構文解析の学習のため、四則演算や比較などは演算子で表し、優先度も持たせる。
      * 演算子は構文解析で組み込み関数に変換する。
    * 数を実装する。
    * コメントを実装する。
    * 足し算、引き算を実装する。
    * 掛け算、割り算、剰余を実装する。
    * カッコを実装する。
    * None、bool、識別子を実装する。
    * 等号、不等号を実装する。
    * 関数呼び出しを実装する。
    * 変数の定義・代入・参照を実装する。
    * seqを実装する。セミコロンを演算子として実装する。
    * scope-endを実装する。
    * if-then-else-endを実装する。elifは後で。
    * while-do-endの構文解析を実装する。
    * funcを実装する。
    * 関数定義 `def ... do ... end` を実装する。
      * 変数定義と無名関数に変換することで構文糖衣として実装する。
    * REPLとファイルからの実行を実装する。シバンもつける。
  * 最小の中間コードインタプリタ
    * どこで読み終わってもよいようにするため、パターンマッチやマクロのような高度な機能よりも先に中間コードインタプリタの考え方を紹介する。
    * 「ツリーウォーク式はシンプルですが、実行速度の面で限界があります。実用的な言語の多くは、より機械語に近い『中間コード』に変換してから実行します。ここでは少し寄り道をして、処理系のもう一つの強力なアプローチを味見してみましょう」
    * 方針
      * 中間言語へコンパイルして仮想マシンで動かす。
      * 仮想マシンはスタックマシンとして実装する。
      * 字句解析・構文解析はそのまま利用する。
      * 仮想マシンをゼロから実装しつつ、値、if、・・・とやはりインクリメンタルに実装する。
    * 定数を実装する。
    * 原理の確認のためadd、mul、equal、printの簡易な実装を行う。
    * seqを実装する。
    * 変数を実装する。
    * setとscopeを実装する。
    * ifを実装する。
    * while-then-endを実装する。
    * 組み込み関数を実装する。
    * ユーザ定義関数を実装する。
    * 中間コードインタプリタの実装はいったんここまでとし、ツリーウォークインタプリタの実装に戻る
* 基本のインタプリタ
  * 機能を拡張する。
    * Identクラスを導入する。
    * 主要部分に型ヒントを入れる。
    * 比較演算子を追加する。
    * 組み込み関数を追加する。Environmentを見やすくする。
    * 単項マイナス、notを追加する。
    * and、or（短絡評価）を実装する。
      * ifに直す形で実装する。
    * elifを実装する。
      * 入れ子のif-then-else-endに変換することで構文糖衣として実装する。
    * returnを実装する。
    * continue, breakを実装する。
      * while-do-then-endにelse節を追加する。
    * 配列を実装する。
      * 配列の生成、参照には[]を用いる。
      * 多次元配列もサポートする。
      * 要素への代入もサポートする。
      * `len`, `push`, `pop`, `slice` などの基本的な組み込み関数を実装する。
    * forを実装する。
      * continue、breakが使えるようにする。
      * whileに変換せず、直接実行する（その方が簡単）。
      * 構文糖衣にしたコードもチラ見せする。
    * 標準ライブラリを実装する。
      * `toil`言語自身で`map`, `filter`, `reduce`などの高階関数や、`range`, `zip`, `first`などを実装する。
    * 文字列を実装する。
      * シングルクォート (`'...'`)による生文字列と、ダブルクォート (`"..."`)によるエスケープ可能な文字列の2種類を実装する。
      * 配列と同様の組み込み関数 (`len`、`slice`や`join`、`format`など) を実装する。
    * Identやtupleを実装し、型変換関数を追加する（`to_str`, `to_int`など）。
* 高度な機能
  * 辞書・オブジェクト指向（風記法）を導入する。
    * 辞書を実装する。
    * ドット記法を実装する。
      * モジュール的な表記が可能になる。
    * メソッド記法を実装する。
      * 辞書でオブジェクト風の表記が可能になる。
    * UFCSを実装する。
      * パイプライン的な表記が可能になる。
      * defclass・defmethodを実装する。クロージャを利用する。
  * パターンマッチを導入する。
    * rest引数`[a, *rest]`を実装する。
      * _（ワイルドカード）は疑似的にサポート。
    * 引数の辞書へのマッチを実装する。
    * 引数のタプルへのマッチを実装する。
    * 分割代入を実装する。
      * bindを使いまわすだけでできる。
    * forでも動作することを確認する。
    * パターンマッチ構文を実装する。
      * リテラルパターンを追加する。
      * Identパターンを実装する。
      * 型パターンを追加する。
    * read（ファイルからの読み込み）を実装し、それを使ってload（プログラムの読み込み）を実装する。
    * アロー関数を実装する。
    * 例外処理を実装する。
  * メタサーキュラー構造
    * eval・eval_expr・applyを実装する。
    * セルフインタプリタ(Toil on Toil)を実装する。
      * ここまでの機能をフルに実装する。マクロなど、ここからさきの機能追加は行わない。
    * Toil on Toil on Toilを実行する。
* マクロとカスタム文法
  * マクロを実装する パート1：ファーストクラスマクロとカスタム文法
    * ここではまず一番わかりやすい形でマクロの正体を掴むための実験として、評価中に展開するマクロを実装する。
      * この実装は後で捨てることになるが、この経験が次の本格的なマクロ実装で生きる。
      * ここでブランチを枝分かれさせる。
      * 冒頭で概念だけ説明する。残りはスキップしてパート２へ進んでもよいように書く。
    * macro()を実装する。
    * quote（機能はquasiquote相当）の機能を実装する。
    * マクロでandとorを実装する。
    * カスタム文法を実装する。
      * マクロとカスタム文法で関数定義 `def` を実装しなおす。
      * マクロでdefmacroを実装する。
      * マクロでforを実装する。
      * マクロでelifを実装する。
      * defclass・defmethodを実装する。
  * マクロを実装する パート2：事前展開型マクロ
    * パート1を読み飛ばしても理解できるように書く。
    * セルフインタプリタ直後の状態に戻って事前展開型のマクロを実装する。
    * parseとevaluateの間にexpandフェーズを入れてマクロを事前に展開するようにする。
    * ツリーを走査するだけのexpandを作る。
    * (op, args) で展開の原理を確認する。
    * macroを実装し、opに直接描いた場合の処理を書く。
    * マクロを変数に記録して使えるようにする。
    * quoteを実装する。
    * defmacro_ のような名前で標準機能相当のマクロを定義する
    * カスタム文法を実装する（パート1のコードからコピー）。
    * カスタム文法でdefmacro_などを呼び出せるようにし、標準の構文糖衣をマクロ化する
* 中間コードインタプリタ
  * 中間コードインタプリタ (Intermediate Code Interpreter:ICI)を機能拡張する。
    * listを実装する。要素参照は組み込み関数で実装済みになっている。
    * dictを実装する。要素参照は組み込み関数で実装済みになっている。
    * ドット記法を実装する（単純なdict要素の参照のみ）
    * bind()で分割代入を実装する。
    * 配列・辞書の要素（インデックス・ドット）への代入を実装する。
    * continueを実装する。
    * breakを実装する。
    * UFCS・メソッド記法を導入する。
    * matchを実装する。
    * try/raiseを実装する。
    * toil on toilを中間コードインタプリタで動かす。
    * toil on toil on toilを中間コードインタプリタで動かす。
  * ツリーウォークと中間コードインタプリタの協調動作
    * 相互呼び出し
    * 実行中コンパイル
    * JITもどき
* おまけ：セルフインタプリタに必要としないために入れなかった機能たち
  * defmodule
  * 遅延評価
  * 関数オーバーロード
