# 書籍の構成案

書籍は以下のように構成する。

* 導入
  * 全体構成の説明
    * どこで読み終わってもまとまった学びがある
    * ファーストクラスマクロの章はスキップも可
    * 中間コードインタプリタは最初に小さく実装した後はしばらく放置する
* 最小のインタプリタ
  * 最小の評価器
    * 方針
      * 字句解析からは始めない。動かせるものから始める。
      * シンプルなツリーウォーク式評価器として実装する。
      * 扱う値は None、bool、int のみ。Python の値をそのまま用いる。
      * この段階では文字列でシンボルを表す。
        * 字句解析・構文解析を導入する段階でシンボルを表す型を導入して文字列が文字列を表すようにする。
      * AST はタプルで表す。
      * 環境は dict を用い、ミュータブルな構造として実装する。
    * 値を実装する。
    * 即席の関数を実装する。（あとで正しく作り直す）
    * 複数の式を順番に評価する seq を実装する。
    * if-then-else を実装する。elif は後で。
    * 変数（定義・参照）を評価する。
    * スコープを実装し、代入を実装する。
    * 組み込み関数を実装する。
    * ユーザ定義関数（動的スコープ）を実装する。
    * ユーザ定義関数（静的スコープ）を実装する。
    * while を実装する。
  * 余談：クロージャでデータ構造
  * 最小の字句解析・構文解析
    * 方針
      * 構文解析の学習のため、四則演算や比較などは演算子で表し、優先度も持たせる。
      * 演算子は構文解析で組み込み関数に変換する。
    * 数を実装する。
    * コメントを実装する。
    * 足し算、引き算を実装する。
    * 掛け算、割り算、剰余を実装する。
    * カッコを実装する。
    * None、bool、識別子を実装する。
    * 等号、不等号を実装する。
    * 関数呼び出しを実装する。
    * 変数の定義・代入・参照を実装する。
    * seq を実装する。セミコロンを演算子として実装する。
    * scope-end を実装する。
    * if-then-else-end を実装する。elif は後で。
    * while-do-end の構文解析を実装する。
    * func を実装する。
    * 関数定義 `def ... do ... end` を実装する。
      * 変数定義と無名関数に変換することで構文糖衣として実装する。
    * REPL とファイルからの実行を実装する。シバンもつける。
  * 最小の中間コードインタプリタ
    * どこで読み終わってもよいようにするため、パターンマッチやマクロのような高度な機能よりも先に中間コードインタプリタの考え方を紹介する。
    * 「ツリーウォーク式はシンプルですが、実行速度の面で限界があります。実用的な言語の多くは、より機械語に近い『中間コード』に変換してから実行します。ここでは少し寄り道をして、処理系のもう一つの強力なアプローチを味見してみましょう」
    * 方針
      * 中間言語へコンパイルして仮想マシンで動かす。
      * 仮想マシンはスタックマシンとして実装する。
      * 字句解析・構文解析はそのまま利用する。
      * 仮想マシンをゼロから実装しつつ、値、if、・・・とやはりインクリメンタルに実装する。
    * 定数を実装する。
    * 原理の確認のため add、mul、equal、print の簡易な実装を行う。
    * seq を実装する。
    * 変数を実装する。
    * set と scope を実装する。
    * if を実装する。
    * while-then-end を実装する。
    * 組み込み関数を実装する。
    * ユーザ定義関数を実装する。
    * 中間コードインタプリタの実装はいったんここまでとし、ツリーウォークインタプリタの実装に戻る
* 基本のインタプリタ
  * 機能を拡張する。
    * Ident クラスを導入する。
    * 主要部分に型ヒントを入れる。
    * 比較演算子を追加する。
    * 組み込み関数を追加する。Environment を見やすくする。
    * 単項マイナス、not を追加する。
    * and、or（短絡評価）を実装する。
      * if に直す形で実装する。
    * elif を実装する。
      * 入れ子の if-then-else-end に変換することで構文糖衣として実装する。
    * return を実装する。
    * continue, break を実装する。
      * while-do-then-end に else 節を追加する。
    * 配列を実装する。
      * 配列の生成、参照には[]を用いる。
      * 多次元配列もサポートする。
      * 要素への代入もサポートする。
      * `len`, `push`, `pop`, `slice` などの基本的な組み込み関数を実装する。
    * for を実装する。
      * continue、break が使えるようにする。
      * while に変換せず、直接実行する（その方が簡単）。
      * 構文糖衣にしたコードもチラ見せする。
    * 標準ライブラリを実装する。
      * `toil` 言語自身で `map`, `filter`, `reduce` などの高階関数や、`range`, `zip`, `first` などを実装する。
    * 文字列を実装する。
      * シングルクォート (`'...'`)による生文字列と、ダブルクォート (`"..."`)によるエスケープ可能な文字列の 2 種類を実装する。
      * 配列と同様の組み込み関数 (`len`、`slice` や `join`、`format` など) を実装する。
    * Ident や tuple を実装し、型変換関数を追加する（`to_str`, `to_int` など）。
* 高度な機能
  * 辞書・オブジェクト指向（風記法）を導入する。
    * 辞書を実装する。
    * ドット記法を実装する。
      * モジュール的な表記が可能になる。
    * メソッド記法を実装する。
      * 辞書でオブジェクト風の表記が可能になる。
    * UFCS を実装する。
      * パイプライン的な表記が可能になる。
      * defclass・defmethod を実装する。クロージャを利用する。
  * パターンマッチを導入する。
    * rest 引数 `[a, *rest]` を実装する。
      * _（ワイルドカード）は疑似的にサポート。
    * 引数の辞書へのマッチを実装する。
    * 引数のタプルへのマッチを実装する。
    * 分割代入を実装する。
      * bind を使いまわすだけでできる。
    * for でも動作することを確認する。
    * パターンマッチ構文を実装する。
      * リテラルパターンを追加する。
      * Ident パターンを実装する。
      * 型パターンを追加する。
    * read（ファイルからの読み込み）を実装し、それを使って load（プログラムの読み込み）を実装する。
    * アロー関数を実装する。
    * 例外処理を実装する。
  * メタサーキュラー構造
    * eval・eval_expr・apply を実装する。
    * セルフインタプリタ(Toil on Toil)を実装する。
      * ここまでの機能をフルに実装する。マクロなど、ここからさきの機能追加は行わない。
    * Toil on Toil on Toil を実行する。
* マクロとカスタム文法
  * マクロを実装するパート 1：ファーストクラスマクロとカスタム文法
    * ここではまず一番わかりやすい形でマクロの正体を掴むための実験として、評価中に展開するマクロを実装する。
      * この実装は後で捨てることになるが、この経験が次の本格的なマクロ実装で生きる。
      * ここでブランチを枝分かれさせる。
      * 冒頭で概念だけ説明する。残りはスキップしてパート２へ進んでもよいように書く。
    * macro()を実装する。
    * quote（機能は quasiquote 相当）の機能を実装する。
    * マクロで and と or を実装する。
    * カスタム文法を実装する。
      * マクロとカスタム文法で関数定義 `def` を実装しなおす。
      * マクロで defmacro を実装する。
      * マクロで for を実装する。
      * マクロで elif を実装する。
      * defclass・defmethod を実装する。
  * マクロを実装するパート 2：事前展開型マクロ
    * パート 1 を読み飛ばしても理解できるように書く。
    * セルフインタプリタ直後の状態に戻って事前展開型のマクロを実装する。
    * parse と evaluate の間に expand フェーズを入れてマクロを事前に展開するようにする。
    * ツリーを走査するだけの expand を作る。
    * (op, args) で展開の原理を確認する。
    * macro を実装し、op に直接描いた場合の処理を書く。
    * マクロを変数に記録して使えるようにする。
    * quote を実装する。
    * defmacro_ のような名前で標準機能相当のマクロを定義する
    * カスタム文法を実装する（パート 1 のコードからコピー）。
    * カスタム文法で defmacro_などを呼び出せるようにし、標準の構文糖衣をマクロ化する
* 中間コードインタプリタ
  * 中間コードインタプリタ (Intermediate Code Interpreter:ICI)を機能拡張する。
    * list を実装する。要素参照は組み込み関数で実装済みになっている。
    * dict を実装する。要素参照は組み込み関数で実装済みになっている。
    * ドット記法を実装する（単純な dict 要素の参照のみ）
    * bind()で分割代入を実装する。
    * 配列・辞書の要素（インデックス・ドット）への代入を実装する。
    * continue を実装する。
    * break を実装する。
    * UFCS・メソッド記法を導入する。
    * match を実装する。
    * try/raise を実装する。
    * toil on toil を中間コードインタプリタで動かす。
    * toil on toil on toil を中間コードインタプリタで動かす。
  * ツリーウォークと中間コードインタプリタの協調動作
    * 相互呼び出し
    * 実行中コンパイル
    * JIT もどき
* おまけ：セルフインタプリタに必要としないために入れなかった機能たち
  * defmodule
  * 遅延評価
  * 関数オーバーロード
