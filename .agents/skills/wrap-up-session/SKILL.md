# セッションの振り返りと文脈の抽出

会話を終了（またはクリア）する前に、次回の新しいセッション（会話）へスムーズに文脈を引き継ぐため、これまでの対話履歴全体を分析して情報を整理してください。

## 実行手順

1.  **対話履歴と既存コンテキストの分析**:
    これまでのユーザーとのやり取り、提案した内容、修正したコード、および合意した事項を振り返ります。
    また、プロジェクトルートにある `session-context.md` を読み込み、すでに記録されている内容を確認します。

2.  **情報の分類と抽出**:
    対話の中で新たに発生した「AIのチェック基準」や「暗黙のルール」など、次セッション以降に引き継ぐべきものを抽出してください。

3.  **2つの形式での出力**:
    抽出した情報を以下の2つのセクションに分けてMarkdown形式でユーザーに提示してください。

    **`session-context.md` の更新提案**
    抽出した情報を踏まえ、既存の `session-context.md` に対してどのような内容を追記・修正すべきか、更新内容（差分や追加テキスト）を提案してください。

    **AGENTS.mdやルール・スキルへの追記提案**
    プロジェクトの `AGENTS.md` や `.agents/rules/`、`.agents/skills/` に直接反映すべきものとして具体的に提案してください。
